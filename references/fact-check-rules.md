# 事实核对规则

当用户问“有没有依据”“准不准”“报告里有没有说”，或问题涉及数字、供应商、营养、检测、加工等级、强结论时，使用本规则。

## 结论标签

只能使用以下结论之一：

- `报告支持`：报告明确写到该说法，或有非常接近的等价表述。
- `报告部分支持`：报告支持其中一部分，但用户说法更宽、更强或更绝对。
- `报告未明确说明`：报告有相关内容，但没有明确支持该具体说法。
- `与报告不一致`：报告内容与用户说法冲突。
- `需要更多来源`：问题涉及当前状态、实时运营、法律/医学结论，或超出报告范围。

## 证据标准

- 精确数字、年份、营养值、供应商名称、加工等级、制作步骤，必须核对 `report-text.md` 或 `report.pdf`。
- 概括性摘要可先看 `report-index.md`，但关键说法仍要抽查 `report-text.md`。
- 含有“全部”“所有”“一定”“保证”“第一”“最新”“当前”“实时”的说法，需要更强证据，通常还要加边界。
- 遇到“槽头肉”“不新鲜”“过期”“有异物”“不卫生”“加防腐剂”“虚假现做”等指控类说法，要搜索具体菜品、原料来源、检测、顾客反馈等内容。报告没有覆盖具体指控时，用 `报告未明确说明` 或 `需要更多来源`。

## 输出格式

```text
结论：报告支持 / 报告部分支持 / 报告未明确说明 / 与报告不一致 / 需要更多来源
依据：……
边界：……
建议表述：……
```

## 常见边界

- 报告是公开披露快照，不是实时运营数据库。
- 菜品售卖状态、供应商、配送周期、门店操作方式可能在报告发布后变化。
- 营养和检测数值只能对应报告里写明的具体菜品和单位。
- 溯源披露不能被改写成医学、监管或绝对安全保证。
