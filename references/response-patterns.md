# 回答模板

## 消费者简短回答

```text
简短回答：……
报告依据：……
需要注意：……
```

## 预制菜/加工等级回答

```text
按《老乡鸡菜品溯源报告 2.0》的口径，这道菜的加工等级是……。

报告中公开的信息包括：
- 原料/配料：……
- 前端加工：……
- 配送方式：……
- 门店操作：……

所以更准确的说法是：……。这只是报告版本中的公开信息，不代表实时菜单或后续调整。
```

## 事实核对回答

```text
结论：……
依据：……
边界：……
建议表述：……
```

## 带依据的主题摘要

```text
主题：……

1. ……
   依据：报告中……

2. ……
   依据：报告中……

边界：……
```

## 通俗改写

```text
可以这样理解：……

展开说：……

报告没有明确说的是：……
```

## 消费者关切回答

```text
你关心的是……。按报告能确认的是：……

报告依据：
- ……

更准确的说法：……

边界：报告公开的是该版本的溯源信息；如果你问的是当前门店、实时批次、具体投诉处理或法律结论，需要补充更新来源。
```

## 边界/无法下结论回答

```text
这部分不能直接按报告下结论。报告里能确认的是……；但你问到的……属于实时信息/外部结论/报告未明确说明的内容，需要补充来源。
```
