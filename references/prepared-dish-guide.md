# 预制菜与菜品加工方式指南

当用户问老乡鸡是不是“预制菜”、某道菜是不是门店现做、中央厨房算不算预制、某道菜怎么加工时，使用本指南。

## 判断流程

1. 如果用户提到具体菜名，先搜索该菜名。
2. 按报告原文给出该菜的 `加工等级`。
3. 说明到店前发生了什么：供应商处理、中央厨房加工、其他前端处理。
4. 说明门店端做了什么：烹饪方式、操作步骤、最佳风味期、出品流程。报告没有写就不要补。
5. 如果用户问的是泛化问题，说明报告的分类体系，不要简单回答“是/不是”。
6. 说明答案基于公开《老乡鸡菜品溯源报告 2.0》，不代表实时菜单或后续调整。

## 必须使用的表达方式

当报告给了更具体的加工等级时，不要只答“是预制菜/不是预制菜”。优先这样说：

```text
按报告口径，这道菜的加工等级是……。报告显示，……在中央厨房/供应商处完成，门店端主要进行……。
```

泛化问题优先这样说：

```text
报告没有把所有菜简单归为一类，而是按加工等级和门店操作工艺分别公开。判断某道菜时，应查该菜对应的溯源页。
```

## 高频问法

- “老乡鸡是不是预制菜？”
- “老乡鸡哪些菜是预制菜？”
- “这个菜是现做还是预制？”
- “老乡鸡是不是所有菜都是现做？”
- “老乡鸡哪些菜只是加热一下？”
- “中央厨房做的算不算预制菜？”
- “半预制是不是就是预制菜？”
- “梅菜扣肉在门店怎么做？”
- “半预制和复热预制有什么区别？”
- “中央厨房加工了什么，门店又做了什么？”
- “菜品加工等级是什么意思？”

## 报告关键词

- `餐厅现做`
- `半预制`
- `央厨半预制`
- `外采半预制`
- `复热预制`
- `原料来源`
- `原料加工`
- `原料配送`
- `餐厅操作工艺`
- `最佳风味期`

## 示例：具体菜品

用户问“老乡鸡梅菜扣肉的做法”时，搜索 `梅菜扣肉`。该菜品页会列出加工等级、配料、营养、供应商、中央厨房处理、冷链配送、烹饪方式和门店操作步骤。回答应来自该菜品页，不要使用通用家常菜谱。

## 禁止事项

- 不要用家常菜谱替代报告里的门店操作工艺。
- 不要因为报告中出现某菜，就声称该菜当前仍在售。
- 不要推断报告未写的配料合规、安全问题或健康影响。
- 除非用户明确要求法律/监管比较并允许外部来源，否则不要只用法规定义回答“算不算预制菜”。
