# 报告索引

这是公开《老乡鸡菜品溯源报告 2.0》的轻量导航索引。引用精确信息前，必须回到 `report-text.md` 或 `report.pdf` 核对。

## 报告基本结构

- 报告按菜品公开溯源信息，常见字段包括基本信息、加工等级、配料、营养成分、原料来源、原料加工、原料配送和餐厅操作工艺。
- 遇到加工方式问题，使用报告自己的分类语言，不要只用泛化的“预制菜/非预制菜”标签。
- 遇到具体菜品，搜索准确菜名，使用对应菜品页作答。

## 加工等级体系

报告涉及餐厅现做、半预制、复热预制等菜品加工分类。用户问“预制菜”时，应先转换为报告里的加工等级框架，再查具体菜品。

建议搜索：

- `加工等级`
- `餐厅现做`
- `半预制`
- `复热预制`
- `原料加工`
- `餐厅操作工艺`

## 示例菜品：梅菜扣肉

报告包含 `梅菜扣肉` 的菜品页。

从报告文本可确认的字段包括：

- 加工等级：半预制
- 味型：咸鲜
- 最佳风味期：3 小时
- 烹饪方式：蒸
- 餐厅操作工艺：将解冻后的虎皮扣肉与调料抓拌，码入扣肉片，放上梅菜，上汽后蒸制。

回答中如涉及用量、供应商、配送比例、营养值、具体步骤，必须搜索 `report-text.md` 中的 `梅菜扣肉`，按报告原文核对后再写。

## 谨慎主题

以下内容要格外谨慎：

- “所有菜品”
- “都是预制菜”
- “完全现做”
- “全国第一”
- “最新门店数”
- 营养值
- 检测结果
- 供应商名称
- 配送周期比例

如果报告没有明确支持用户措辞，要弱化表述或标注“报告未明确说明”。
